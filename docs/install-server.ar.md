# تثبيت خادم جسور خطوة بخطوة

*[English version](install-server.md)*

هذا الدليل لمن **لم يشغّل خادمًا من قبل**. ستستأجر خادمًا صغيرًا على الإنترنت، وتعطيه اسمًا، ثم تلصق **أمرًا واحدًا**
وتجيب عن بضعة أسئلة. والأمر يتولى كل الباقي: إعدادات الحماية، والبرامج، وشهادة التشفير، وكلمات المرور، والنسخ
الاحتياطي اليومي.

يستغرق ذلك نحو **30 دقيقة**، معظمها انتظار. لا تدفع إلا ثمن الخادم (نحو 4–6 دولارات شهريًا) واسم النطاق (نحو 10
دولارات سنويًا)، أما جسور نفسه فمجاني.

> **قبل أن تبدأ، اقرأ [مسؤولية المضيف](../README.md#read-this-before-you-host).** حين تشارك اتصالك، ترى المواقع التي
> يزورها غيرك **عنوانك أنت**.

النسخة اليدوية من كل خطوة، مع أسبابها، موجودة في [self-hosting.md](self-hosting.md) (بالإنجليزية). لا تحتاج إليها
لتتبع هذه الصفحة.

---

## ما تحتاج إليه

| | |
|---|---|
| **خادم** (VPS) | تستأجره من أي شركة استضافة. اختر **Ubuntu 24.04**، و**2 جيجابايت ذاكرة**، ومعالجًا واحدًا. الخطوة 1 |
| **اسم نطاق** (دومين) | أي اسم تملكه، من أي مسجّل نطاقات (Namecheap أو GoDaddy أو Cloudflare أو غيرها). ستستخدم جزءًا منه مثل `josour.yourname.com`. الخطوة 2 |
| **حاسوب** | Windows 10/11 أو Mac، تكتب منه الأوامر. لا يُثبَّت عليه شيء للخادم |
| **بريد إلكتروني** | لحساب المسؤول، ولتنبيهات شهادة التشفير |

في هذه الصفحة كلها يرمز <span dir="ltr">`josour.example.com`</span> إلى اسم خادمك، و<span dir="ltr">`203.0.113.10`</span>
إلى عنوانه. **ضع مكانهما ما يخصك.**

---

## الخطوة 1: استئجار الخادم

في أي شركة استضافة تختارها (Hetzner أو DigitalOcean أو Vultr أو Linode أو Contabo أو OVH، وأيها يصلح):

1. أنشئ خادمًا جديدًا (قد يُسمّى *VPS* أو *Droplet* أو *Instance* أو *Cloud Server*).
2. **نظام التشغيل:** Ubuntu **24.04** (ويعمل أيضًا 22.04 وDebian 12).
3. **الحجم:** أصغر باقة فيها **2 جيجابايت ذاكرة** (1 جيجابايت تعمل، لكن التثبيت أبطأ).
4. **الموقع:** في مكان بين الشخصين اللذين سيستخدمانه. لمغترب يستخدم اتصالًا في بلده، اختر أقرب منطقة إلى بلده. بين مصر
   والسعودية مثلًا، منطقة في الخليج أسرع من أوروبا.
5. **الدخول:** اختر **كلمة مرور root** (أو مفتاح SSH إن كنت تعرفه)، واكتب كلمة المرور عندك.
6. أنشئ الخادم. بعد دقيقة تُظهر لوحة التحكم **عنوان IPv4** الخاص به، وهو أربعة أرقام مثل <span dir="ltr">`203.0.113.10`</span>.
   اكتبه عندك.

> بعض الشركات تجعلك تدخل باسم مستخدم مثل `ubuntu` أو `admin` بدل `root`. لا مشكلة: استخدم ذلك الاسم حيثما ذكرت هذه
> الصفحة `root`.

---

## الخطوة 2: إعطاء الخادم اسمًا

في الشركة التي اشتريت منها النطاق، افتح **إعدادات DNS** للنطاق (قد تُسمّى *DNS Records* أو *Zone Editor* أو *Advanced
DNS*)، ثم **أضف سجلًا**:

| النوع (Type) | الاسم (Name / Host) | القيمة (Value / Points to) | TTL |
|---|---|---|---|
| `A` | `josour` | <span dir="ltr">`203.0.113.10`</span>، أي عنوان خادمك | تلقائي (أو 5 دقائق) |

بالاسم `josour` يصبح الوصول إلى الخادم عبر <span dir="ltr">`josour.<نطاقك>`</span>، مثل <span dir="ltr">`josour.example.com`</span>.

- **سجل `A` فقط.** إن وُجد سجل `AAAA` للاسم نفسه فاحذفه.
- **في Cloudflare** اجعل السجل **DNS only** (سحابة رمادية لا برتقالية).
- يعمل السجل الجديد عادة خلال 5 إلى 30 دقيقة. ويتحقق منه برنامج التثبيت بنفسه، وينتظر إن لم يكن جاهزًا.

---

## الخطوة 3: فتح المنافذ (فقط إن كان لدى شركة الاستضافة جدار حماية)

بعض الشركات (مثل AWS وOracle Cloud وGoogle Cloud وAzure، وأحيانًا Hetzner) لديها في لوحة التحكم **جدار حماية**
(Firewall أو Security Group) يمنع كل شيء افتراضيًا. إن كان لدى شركتك واحد، فاسمح بهذه المنافذ **الواردة**:

| البروتوكول | المنفذ | الغرض |
|---|---|---|
| TCP | 22 | الاتصال بالخادم (SSH) |
| TCP | 80 | الحصول على الشهادة |
| TCP | 443 | التطبيق ولوحة التحكم |
| UDP | 443 | الشيء نفسه، بسرعة أكبر |
| TCP | 8443 | المُرحِّل (relay): ما يجعل الجلسة تعمل بين أي شبكتين |

إن لم يكن لدى شركتك هذا الإعداد فتخطَّ الخطوة. فبرنامج التثبيت يضبط جدار حماية الخادم نفسه بنفسه.

---

## الخطوة 4: الاتصال بالخادم

**على Windows:** افتح قائمة ابدأ، واكتب **PowerShell** وافتحه. **على Mac:** افتح **Terminal** (من Applications ثم
Utilities).

اكتب ما يلي، بعنوان خادمك، ثم اضغط Enter:

<div dir="ltr">

```bash
ssh root@203.0.113.10
```

</div>

- في المرة الأولى يسأل *"Are you sure you want to continue connecting?"*: اكتب `yes` واضغط Enter.
- ثم يطلب كلمة المرور. **لا يظهر شيء على الشاشة أثناء كتابتها**، وهذا طبيعي. اكتبها (أو الصقها بزر الفأرة الأيمن)
  واضغط Enter.

أنت داخل الخادم حين ينتهي السطر بشيء مثل <span dir="ltr">`root@your-server:~#`</span>. كل الأوامر التالية تُكتب هناك.

> **النسخ واللصق:** في PowerShell وTerminal الصق **بزر الفأرة الأيمن** (Windows) أو **Cmd+V** (Mac). قد لا يعمل
> Ctrl+V.

---

## الخطوة 5: تثبيت جسور

الصق هذين السطرين واضغط Enter:

<div dir="ltr">

```bash
curl -fsSL https://raw.githubusercontent.com/mo-shaker/josour/main/deploy/install.sh -o josour-install.sh
sudo bash josour-install.sh
```

</div>

يطرح خمسة أسئلة (بالإنجليزية). اكتب الإجابة واضغط Enter. وحيث تظهر قيمة بين `[قوسين]`، فالضغط على Enter وحده يقبلها.

| السؤال | ماذا تجيب |
|---|---|
| **The server's name** (اسم الخادم) | الاسم من الخطوة 2، مثل <span dir="ltr">`josour.example.com`</span>، بدون <span dir="ltr">`https://`</span> |
| **Your email address** (بريدك) | بريدك. لا تراسلك عليه Let's Encrypt، الجهة التي تصدر الشهادة المجانية، إلا إن كانت في الشهادة مشكلة |
| **Administrator's email** (بريد المسؤول) | البريد الذي ستدخل به إلى لوحة التحكم والتطبيق. اضغط Enter لاستخدام البريد نفسه |
| **Administrator's name** (اسم المسؤول) | اسمك كما سيراه الآخرون |
| **Password** (كلمة المرور، مرتين) | كلمة مرور المسؤول، **8 أحرف على الأقل**. لا يظهر شيء أثناء الكتابة، وهذا طبيعي |

بعدها يعمل وحده **من 5 إلى 15 دقيقة**، ويعرض كل خطوة وينهي كلًا منها بكلمة `done`:

<div dir="ltr">

```
[1/8] Checking that josour.example.com points at this server
[2/8] Preparing the system (updates, firewall, automatic security updates)
[3/8] Installing Docker
[4/8] Fetching Josour
[5/8] Writing the settings
[6/8] Starting the server (the first start builds it: allow 5 to 10 minutes)
[7/8] The administrator account
[8/8] A first backup, and tidying up
```

</div>

وينتهي بعبارة **"Josour is installed"** وملخص فيه: عنوان لوحة التحكم، والعنوان الذي تكتبه في التطبيق، ومكان حفظ
الإعدادات. **صوّر هذا الملخص أو انسخه في مكان ما.**

**إن توقف برسالة خطأ**، فالرسالة تقول ما المشكلة. أكثر الأسباب شيوعًا أن الاسم من الخطوة 2 لم يجهز بعد، أو أن منفذًا
من الخطوة 3 مغلق. أصلح ذلك ثم **شغّل <span dir="ltr">`sudo bash josour-install.sh`</span> مرة أخرى**. تشغيله مرارًا
آمن، ويكمل من حيث توقف.

**احتفظ بنسخة من ملف الإعدادات.** فيه كلمات مرور الخادم، ومن دونه تصبح استعادة النسخة الاحتياطية أصعب بكثير. من
**حاسوبك** (نافذة PowerShell أو Terminal جديدة، لا النافذة المتصلة بالخادم):

<div dir="ltr">

```bash
scp root@203.0.113.10:/opt/josour/deploy/.env josour-settings-backup.txt
```

</div>

احفظ هذا الملف في مكان خاص، مثل مدير كلمات المرور، ولا ترسله لأحد.

## الخطوة 6: الدخول إلى لوحة التحكم

افتح **<span dir="ltr">`https://josour.example.com/admin`</span>** في المتصفح، وادخل ببريد المسؤول وكلمة مروره. اللوحة
بالعربية، والرابط في أعلاها يحوّلها إلى الإنجليزية.

ثم مرة واحدة:

1. **فعّل التحقق بخطوتين.** من **حسابي** اضبط تطبيق مصادقة (Google Authenticator أو Microsoft Authenticator أو
   1Password أو Bitwarden أو غيرها): امسح الرمز بهاتفك واكتب الأرقام الستة التي يعرضها. من الآن فصاعدًا يطلب الدخول
   إلى اللوحة رمزًا من هاتفك أيضًا.
2. **قرر من يحق له إنشاء حساب**، من **الإعدادات** ثم **التسجيل من التطبيق**:
   - **بموافقة المسؤول** (الافتراضي): يستطيع أي شخص لديه التطبيق التسجيل، وتوافق أنت على كل شخص من **طلبات التسجيل**.
     هذا الاختيار المناسب لمعظم الناس.
   - **مغلق**: أنت وحدك تنشئ الحسابات، من **المستخدمون**. الأكثر إحكامًا لمجموعة خاصة صغيرة.
   - **مفتوح**: يستطيع أي شخص التسجيل والاستخدام فورًا. غير منصوح به.

## الخطوة 7: تثبيت التطبيق على كل حاسوب

كل شخص يثبّت التطبيق: من يشارك اتصاله (**المضيف**) ومن يستخدمه (**الضيف**). نزّله من هنا:

| الحاسوب | التنزيل |
|---|---|
| **Windows** 10/11 | [Josour-win-x64.exe](https://github.com/mo-shaker/josour/releases/latest/download/Josour-win-x64.exe) |
| **Mac** بمعالج Apple (M1 أو M2 أو M3 أو M4…) | [Josour-macos-arm64.dmg](https://github.com/mo-shaker/josour/releases/latest/download/Josour-macos-arm64.dmg) |
| **Mac** بمعالج Intel (أجهزة Mac الأقدم) | [Josour-macos-x64.dmg](https://github.com/mo-shaker/josour/releases/latest/download/Josour-macos-x64.dmg) |

(أي Mac لديك؟ من قائمة Apple اختر *About This Mac*: إن ظهر "Chip: Apple M…" فهو معالج Apple، وإن ظهر "Processor: Intel…"
فهو Intel.) وكل الإصدارات موجودة في [صفحة الإصدارات](https://github.com/mo-shaker/josour/releases).

**Windows:** ضع الملف في مكان دائم، مثل مجلد <span dir="ltr">`C:\Josour`</span>، وانقر عليه نقرًا مزدوجًا. في المرة
الأولى يقول Windows *"Windows protected your PC"*: انقر **More info** ثم **Run anyway**. (التطبيق غير موقّع بشهادة
مدفوعة، وهذا [قرار مقصود](decisions/0011-no-code-signing-certificate.md).)

**Mac:** افتح ملف `.dmg` واسحب **Josour** إلى **Applications**. في المرة الأولى يرفض macOS فتحه:
- **macOS 15 وما بعده:** انقر **Done**، ثم اذهب إلى **System Settings ← Privacy & Security**، وانزل إلى الأسفل، وانقر
  **Open Anyway** بجانب Josour، وأكّد بكلمة مرورك.
- **macOS 14 وما قبله:** انقر **بالزر الأيمن** على Josour في Applications ثم **Open** ثم **Open**.

**حين يُفتح التطبيق أول مرة** يطلب:

1. **عنوان الخادم:** <span dir="ltr">`https://josour.example.com`</span>.
2. **تسجيل الدخول** (للمسؤول)، أو **إنشاء حساب** لكل شخص آخر. في وضع "بموافقة المسؤول" ينتظر الحساب الجديد حتى توافق
   عليه من لوحة التحكم، في **طلبات التسجيل**.

## الخطوة 8: ربط الشخصين

لا يشارك الناس اتصالهم إلا مع **جهات اتصالهم**. في التطبيق يفتح أحدهما تبويب **جهات الاتصال**، وينقر **دعوة**، ويكتب
**بريد** الآخر. ثم يقبل الآخر الدعوة في تطبيقه. (لا تُرسَل رسالة بريد فعلًا؛ تظهر الدعوة داخل التطبيق.)

> **لمجموعة صغيرة يثق أفرادها ببعضهم**، يمكنك ربط الجميع دفعة واحدة. على الخادم:
> <span dir="ltr">`cd /opt/josour/deploy && docker compose exec api python manage.py seed-contacts --all-active`</span>

## الخطوة 9: التجربة

الأفضل أن يكون الحاسوبان على **شبكتين مختلفتين**، مثل المضيف على Wi-Fi المنزل والضيف على نقطة اتصال من هاتف.

1. على **الحاسوبين**، افتح <span dir="ltr">`https://api.ipify.org`</span> في المتصفح ودوّن الرقم. يجب أن يختلف الرقمان.
2. **المضيف:** افتح تبويب **مشاركة اتصالي** وفعّل المشاركة.
3. **الضيف:** في تبويب **جهات الاتصال**، انقر **استخدم اتصاله** بجانب المضيف، واختر المدة.
4. **المضيف:** تظهر نافذة تطلب الإذن. اقرأها ثم **اقبل**.
5. **الضيف:** تُفتح صفحة فحص وحدها وتعرض عنوان المضيف. أعد تحميل <span dir="ltr">`https://api.ipify.org`</span> في أي
   متصفح: يظهر الآن **رقم المضيف**. هذا هو المنتج كله.
6. **أنهِ** الجلسة من أي طرف. يعرض <span dir="ltr">`https://api.ipify.org`</span> على جهاز الضيف رقمه هو من جديد.

## تشغيل الخادم بعد ذلك

### التحديث إلى إصدار جديد

اتصل بالخادم (الخطوة 4) وشغّل:

<div dir="ltr">

```bash
sudo bash /opt/josour/deploy/install.sh
```

</div>

يأخذ نسخة احتياطية، وينزّل أحدث إصدار، ويعيد البناء والتشغيل، دون أن يسأل شيئًا ودون أن يغيّر إعداداتك. افعل ذلك
حين لا يكون أحد في جلسة، لأن الجلسة الجارية أثناء التحديث تنتهي. ثم ثبّت التطبيق الجديد على الحواسيب أيضًا (الخطوة 7)،
والتطبيق يحتفظ بإعداداته وبتسجيل الدخول.

### النسخ الاحتياطي

يكتب الخادم نسخة احتياطية من قاعدة بياناته **كل يوم** في <span dir="ltr">`/opt/josour/deploy/backups`</span>، ويحتفظ
بآخر أسبوعين. لكن نسخة على الخادم نفسه لا تنجو إن ضاع الخادم، فانسخها إلى حاسوبك بين حين وآخر (من حاسوبك لا من الخادم):

<div dir="ltr">

```bash
scp -r root@203.0.113.10:/opt/josour/deploy/backups josour-backups
```

</div>

لاستعادة نسخة، أو للانتقال إلى خادم جديد: [self-hosting.md، الجزء 7](self-hosting.md#7-running-it).

## إن لم يعمل شيء

| ما تراه | ما تفعله |
|---|---|
| يقول برنامج التثبيت إن الاسم *does not point at this server* | سجل DNS من الخطوة 2 غير موجود، أو فيه خطأ، أو لم يعمل بعد. راجعه وانتظر 10 دقائق، ثم اضغط Enter ليفحص مجددًا |
| يقول برنامج التثبيت *another program already uses port 80/443* | الخادم ليس جديدًا (يشغّل موقعًا بالفعل). استخدم خادمًا جديدًا فارغًا |
| يقول برنامج التثبيت *no certificate yet* | المنفذ 80 أو 443 مغلق في جدار حماية شركة الاستضافة (الخطوة 3)، أو سجل DNS لم يجهز. أصلح ذلك وشغّل برنامج التثبيت مجددًا |
| يقول `ssh` *Connection refused* أو *timed out* | العنوان خطأ، أو الخادم ما زال يبدأ، أو المنفذ 22 مغلق في جدار حماية الشركة |
| يقول `ssh` *Permission denied* | كلمة المرور خطأ، أو الشركة تريد اسم مستخدم غير `root` (الخطوة 1) |
| يحذّر `ssh` من أن *host identification has changed* | طبيعي بعد إعادة تثبيت الخادم: شغّل <span dir="ltr">`ssh-keygen -R 203.0.113.10`</span> على حاسوبك ثم اتصل مجددًا |
| يقول التطبيق إن عنوان الخادم خطأ | افتح <span dir="ltr">`https://josour.example.com/healthz`</span> في المتصفح؛ يجب أن يظهر <span dir="ltr">`"product":"josour"`</span>. إن لم يظهر، شغّل برنامج التثبيت مجددًا واقرأ رسائله |
| يقول التطبيق إن الحساب *بانتظار الموافقة* | وافق عليه من لوحة التحكم، في **طلبات التسجيل** |
| لا يظهر المضيف للضيف | لم يصبحا جهتي اتصال بعد (الخطوة 8)، أو لم يفعّل المضيف المشاركة (تبويب **مشاركة اتصالي**) |
| لا تتصل الجلسة أبدًا | المنفذ **8443** مغلق في جدار حماية شركة الاستضافة (الخطوة 3) |
| لا إنترنت على جهاز الضيف بعد تعطّل التطبيق | افتح جسور مجددًا فيعيد الإعدادات. أو أوقف البروكسي يدويًا: في Windows من *Settings ← Network & internet ← Proxy*، وفي Mac من *System Settings ← Network ← الاتصال ← Details ← Proxies* |
| ضاع الهاتف الذي عليه تطبيق المصادقة | انظر [self-hosting.md، الجزء 8](self-hosting.md#8-if-it-does-not-work) |

يكتب برنامج التثبيت كل ما فعله في <span dir="ltr">`/var/log/josour-install.log`</span> على الخادم. إن طلبت مساعدة من
أحد فهذا الملف ما سيحتاج إليه، لكن راجعه أولًا واحذف منه ما لا تريد مشاركته.

</div>
