# ADR-0006: مكتبة Multiplexing للنفق

**الحالة:** مفتوح. يُقرر في الأسبوع 2 بعد نموذج يومين.

## الخياران
1. `Nerdbank.Streams.MultiplexingStream` (MIT، مستخدم داخل Visual Studio): قنوات فوق أي `Stream` مع Backpressure عبر `System.IO.Pipelines`، اسم القناة يحمل `host:port`.
2. Framing يدوي وفق `docs/protocol.md` القسم 5 (نحو 600 سطر + اختبارات).

## معايير القرار
- سلوك Backpressure الفعلي: مستهلك بطيء على قناة لا يعطل الأخرى.
- القدرة على رفض فتح القناة بسبب مرمّز (`OPEN_FAIL` reason).
- الأداء عبر TLS محلي: 100 MB، و256 قناة متزامنة.
- حجم الاعتماد وسهولة التتبع عند الأعطال.
